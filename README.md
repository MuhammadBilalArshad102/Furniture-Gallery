# Furniture Gallery

A multi-page furniture e-commerce site built with vanilla JavaScript — products are rendered entirely from data, nothing is hardcoded in the HTML.

## Features
- Product & category data driven entirely by JS arrays of objects
- Live search, price-range and sort filtering (no page reload)
- Standalone product detail page (reads product ID from the URL)
- Shopping cart persisted to `localStorage`, synced across pages
- Checkout page with shipping options, promo codes and order summary
- Blog section with static post data

## Pages
- Home (product grid + filters)
- Product Detail
- Checkout

## Tech Stack
HTML5 · CSS3 · JavaScript · localStorage

## Run Locally
```bash
git clone https://github.com/MuhammadBilalArshad102/Furniture-Gallery.git
cd Furniture-Gallery
```
Open `index.html` in your browser.
